You are running Oppia in a developer environment, where jobs can only be run synchronously.

This has the following developer-only consequences:

  • Once a job is started, it cannot be canceled.
  • Jobs will terminate after 10 minutes.
  • Jobs will terminate after leaving this tab or navigating away from the page.
  • Terminated jobs will not appear in the job history.
  • Terminated jobs that mutate the datastore will leave the datastore in an undefined state.
